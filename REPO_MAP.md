# 1. Visão Geral da Arquitetura
- **Desktop GUI (`/views`, `/controllers`, `main.py`)**: Aplicação PDV/ERP em Python com CustomTkinter, Tkinter/TTK, Pillow e Matplotlib.
- **API & Web Mobile PWA (`api_mobile.py`, `/static`)**: Backend REST em FastAPI (JWT Bearer) servindo SPA/PWA responsiva (HTML5/CSS3/JS Vanilla + HTML5-QRCode) via Cloudflare Tunnel (`config.yml`).
- ** Persistência (`database/`)**: Banco relacional local SQLite (`estoque_loja.db` em WAL mode) gerenciado via SQLAlchemy ORM (Desktop) e `sqlite3` nativo (FastAPI/Monitor).
- **Utilitários e Operação (`utils_*.py`, `backup.py`, `*.bat`)**: Impressão térmica/etiquetas (QRCode/Code128), resolução cromática e rotinas de backup local/pendrive.

# 3. Esquema Resumido do Banco de Dados
- `atributos`: (`id` PK, `categoria` IDX, `nome`) -> Lido/Escrito por `controllers/config_ctrl.py`, `migrate.py`.
- `produtos`: (`id` PK, `modelo_nome`, `marca`, `tecido`, `corte`, `cores_tags`) -> Lido/Escrito por `controllers/estoque_ctrl.py`, `api_mobile.py`, `database/conexao.py`, `migrate.py`.
- `produto_variacoes`: (`id` PK, `produto_id` FK->`produtos.id`, `tamanho`, `cor`, `cor_hex`, `codigo_barras` IDX, `estoque`, `preco_custo`, `preco_venda`, `foto_path`) -> Lido/Escrito por `controllers/estoque_ctrl.py`, `api_mobile.py`, `views/tela_principal.py`, `database/conexao.py`, `migrate.py`.
- `vendas`: (`id` PK, `variacao_id` FK->`produto_variacoes.id`, `modelo_nome`, `marca`, `cor`, `tamanho`, `quantidade`, `valor_unitario`, `valor_total`, `preco_custo`, `data_venda` IDX, `forma_pagamento`) -> Lido/Escrito por `controllers/estoque_ctrl.py`, `api_mobile.py`, `views/tela_principal.py`, `database/conexao.py`, `migrate.py`.
- `clientes`: (`id` PK, `nome` UNIQUE, `telefone`, `limite_credito`, `dia_preferencial_pagamento`) -> Lido/Escrito por `controllers/fiado_ctrl.py`, `api_mobile.py`, `database/conexao.py`, `migrate.py`.
- `conta_fiado`: (`id` PK, `cliente_id` FK->`clientes.id`, `tipo_movimentacao` ['DEBITO'|'CREDITO'], `valor`, `data_movimentacao` IDX, `data_vencimento_lote` IDX, `descricao`) -> Lido/Escrito por `controllers/fiado_ctrl.py`, `controllers/estoque_ctrl.py`, `api_mobile.py`, `views/tela_principal.py`, `database/conexao.py`, `corrigir_banco.py`, `migrate.py`.

# 4. Fluxos Críticos (Rastreamento Rápido)
- **Venda PDV Desktop (À Vista / Fiado)**: `views/tela_venda.py (_finalizar_venda)` -> `controllers/estoque_ctrl.py (registrar_venda_lote)` -> `database/models.py (UPDATE ProdutoVariacao.estoque, INSERT Venda)` -> [Se Fiado] `controllers/fiado_ctrl.py (_executar_registro_compra_fiado)` -> `database/models.py (INSERT ContaFiado)`.
- **Venda PDV Mobile (Scanner / Catálogo)**: `static/app.js (aoLerCodigo / adicionarPorCodigo)` -> `api_mobile.py (GET /api/qrcode/{codigo})` -> `static/app.js (finalizarVenda)` -> `api_mobile.py (POST /api/vendas : registrar_venda)` -> `SQLite (UPDATE produto_variacoes, INSERT INTO vendas, INSERT INTO conta_fiado)`.
- **Cadastro / Edição de Grade Desktop**: `views/tela_cadastro.py (_processar_salvamento)` -> `controllers/estoque_ctrl.py (salvar_grade_dinamica)` -> `utils_cores.py (resolver_cor_hex)` -> `database/models.py (INSERT/UPDATE Produto, INSERT/UPDATE/DELETE ProdutoVariacao)`.
- **Cadastro / Edição de Estoque Mobile**: `static/app.js (salvarProduto)` -> `api_mobile.py (POST /api/estoque/produto : criar_produto | PUT /api/estoque/produto/{id} : atualizar_produto)` -> `SQLite (INSERT/UPDATE produtos, INSERT/UPDATE/DELETE produto_variacoes)`.
- **Bipe Global de Código de Barras (Desktop)**: `views/tela_principal.py (_capturar_bipe_global -> _processar_bipe)` -> `controllers/estoque_ctrl.py (buscar_por_codigo)` -> `views/tela_principal.py (_ir_venda)` -> `views/tela_venda.py (adicionar_via_bipe -> _adicionar_variacao_direta)`.
- **Amortização / Pagamento de Fiado**:
  - Desktop: `views/tela_fiado.py (_confirmar_pagamento)` -> `controllers/fiado_ctrl.py (registrar_pagamento)` -> `database/models.py (INSERT ContaFiado [CREDITO])`.
  - Mobile: `static/app.js (confirmarPagamento)` -> `api_mobile.py (POST /api/fiado/pagar : pagar_fiado)` -> `SQLite (INSERT INTO conta_fiado [CREDITO])`.
- **Sincronização Live Desktop <-> Mobile**:
  - Desktop Polling: `views/tela_principal.py (_verificar_mudancas_banco)` -> `SQLite (SELECT COUNT/SUM em vendas, produto_variacoes, conta_fiado)` -> `tela_atual (atualizar_dados)`.
  - Mobile Polling: `static/app.js (iniciarPollingSincronizacao)` -> `api_mobile.py (GET /api/estoque, GET /api/fiado/clientes, GET /api/financeiro/resumo, GET /api/vendas/hoje)`.
- **Relatórios e Dashboard Analítico**: `views/tela_dashboard.py (carregar_dados_e_renderizar_dashboard)` -> `controllers/dash_ctrl.py (obter_dados_vendas_filtrados / calcular_metricas_financeiras)` -> `controllers/estoque_ctrl.py (buscar_dados_dashboard / buscar_dados_estoque_dashboard)` -> `database/models.py (SELECT Venda OUTER JOIN ProdutoVariacao OUTER JOIN Produto)`.
- **Geração e Impressão de Etiquetas**: `views/tela_estoque.py (_acao_ver_qrcode / _acao_barcode)` -> `controllers/estoque_ctrl.py (buscar_produto_completo)` -> `utils_impressao.py (gerar_etiqueta -> imprimir_etiqueta)`.
